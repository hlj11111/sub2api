# OpenAI 独立搜索控制

OpenAI API Key 上游支持普通 `/v1/responses`，不代表它也实现了
`/v1/alpha/search`。对于返回 `channel does not support /v1/alpha/search`
的渠道，可在账号的新建或编辑页面关闭 **支持独立搜索（/v1/alpha/search）**；
批量编辑支持单独修改这一项。

- 未配置时保持原有行为，默认允许独立搜索参与调度。
- 关闭后，普通调度、会话粘性和高级调度均跳过该账号的独立搜索能力。
  普通会话、模型映射、Responses 路由及其他端点能力不受此开关影响。
- 开启只是允许参与搜索调度，不会为上游增加接口能力，也不绕过已有端点限制。
- 若分组内没有可承接搜索的账号，搜索请求会失败；不会伪造搜索结果。

配置保存在账号凭据 JSON 的布尔字段 `openai_alpha_search_enabled` 中：

```json
{"openai_alpha_search_enabled": false}
```

无需数据库迁移。编辑、批量更新、导入导出沿用账号凭据存储机制。

API Key 上游的独立搜索 404/405，以及 400/500/501 中明确声明
`/alpha/search` 不支持的错误，只触发本次请求换号，不重试同一账号，
也不写入普通模型的连续失败冷却、账号错误率或池模式健康熔断。
普通 5xx、认证、配额等错误仍沿用既有处理，避免掩盖真实上游故障。

修改上线后才会生效。关闭开关不负责清除已由其他请求形成的模型冷却状态。
